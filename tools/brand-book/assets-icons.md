# Icons

The site's own filled navigation glyphs. Each is single-ink, so pick the file whose ink suits the ground:

- **arrow-up / arrow-down / arrow-left / arrow-right.svg**: ink #121514 (near-black), for light grounds.
- **arrow-right-up.svg**, **close-grey.svg**, **menu-tab-mob.svg**: ink #727272 (grey), for "open link", close and the mobile menu tab on dark grounds.
- **done-mark.svg**: white check, for dark grounds. **done-mark-dark.svg**: #121514 check, for light grounds.
- **team-linkedin.svg**, **team-mail.svg**: white, for team cards.

For any other interface icon use Lucide (`lucide-react`), 24px, 2px stroke, `currentColor`.
